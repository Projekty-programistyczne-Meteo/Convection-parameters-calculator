Cypress is a frontend test automation tool (framework) for regression testing of web applications including End-to-End (E2E), integration, and unit tests. Cypress runs on Windows, Linux, and macOS.

> 1. Go to cypress section in `app\cpc\tests`.
> 2. Type `npm ci` (if you hadn't done it already).
> 3. For GUI testing run: `npx cypress open`, and then you can choose E2E or component testing.
> 4. For console quick testing run: `npx cypress run --component` or `npx cypress run --e2e`.
