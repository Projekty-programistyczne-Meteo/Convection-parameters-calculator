# Testing Documentation

This document provides a high-level entry point for the test-related documentation in the project. It links to the separate test docs that describe how end-to-end and component testing are organized, configured, and run.

## Test Documentation Map

- [Component Testing](component-testing.md) - describes Cypress component test structure, support files, and commands.
- [E2E Testing](e2e-testing.md) - describes end-to-end test structure, page object model, and test commands.
- [Run Tests](run-tests.md) - describes app-level scripts, Cypress run commands, and test execution notes.

## Purpose

The `tests-documentation.md` file is intended to be a single entry point for contributors who want to understand the project's testing approach without reading every individual test document first.

It covers the following:

- where test files are located,
- what each test document contains,
- how component and end-to-end testing relate,
- how to execute tests from the terminal.

## How to use this document

Start here when you need an overview of the testing documentation.

Then follow the links above to view details about component testing, E2E testing, or the exact commands used to run the test suites.
